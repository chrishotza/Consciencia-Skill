# V42 — Matriz completa 4×4 de compatibilidad de referencias

V42 amplía el análisis de referencias cross-history a las 16 combinaciones entre template history-pair de prueba y template history-pair de referencia.

Para cada par de prueba se testean las referencias 0, 1, 2 y 3. Los history seeds de prueba 200–209 y los de referencia 230–239 son disjuntos.

Se conserva el readout reference-based signed-affinity. También permanecen sin cambios los seis puntos ciegos, nueve contextos memory/pressure, radio 1.1, ángulos 30° y 150°, input futuro exactamente cero y seeds de continuación disjuntas.

## Estadística mecanística primaria

contraste del mismo par − media de los contrastes de los otros tres templates de referencia.

La inferencia se realiza sobre 40 bloques history-seed de prueba, estratificados por template test-pair.

La matriz permite distinguir:

- una estructura de compatibilidad diagonal;
- transferencia amplia entre todos los tipos de par;
- o una matriz de compatibilidad más compleja.

El experimento no establece consciencia, experiencia subjetiva ni sentiencia.

# V42 — Full 4×4 Reference Compatibility Matrix

V42 expands the cross-history reference analysis to all 16 combinations of test history-pair template and reference history-pair template.

For each test pair, reference pairs 0, 1, 2, and 3 are tested. Test history seeds 200–209 and reference history seeds 230–239 are disjoint.

The reference-based signed-affinity readout is preserved. The six blind parameter points, nine memory/pressure contexts, radius 1.1, angles 30° and 150°, exactly zero future input, and disjoint continuation seeds are unchanged.

Primary mechanistic statistic:
same-pair contrast − mean contrast from the three other reference-pair templates.

Inference is performed over 40 test history-seed blocks, stratified by test-pair template.

This distinguishes:
- a diagonal compatibility structure;
- broad transfer across all pair types;
- or a more complex compatibility matrix.

The experiment does not establish consciousness, subjective experience, or sentience.
