# V45 — Memory interna bajo una sonda novedosa común

V45 prueba si la historia interna retenida cambia el procesamiento de un nuevo input externo.

Primero se establece cada uno de cuatro templates históricos. Después, todas las historias reciben la misma sonda determinista novedosa. La sonda es idéntica entre clases, por lo que el input externo actual no identifica la clase.

Un clasificador leave-one-parameter-out se entrena con ejecuciones limpias y observa únicamente la trayectoria futura del state. Nunca recibe memory ni pressure.

Para puntos paramétricos reservados, se sustituye memory de una clase histórica donante mientras state y pressure del receptor permanecen fijos. La estadística primaria es el cambio emparejado en la probabilidad donor-minus-receiver relativo al receptor intacto.

Pressure replacement y state replacement son controles.

Esto prueba procesamiento dependiente de contexto ante un estímulo posterior común. Sigue siendo un test de dinámica computacional y no establece consciencia, experiencia subjetiva, sentiencia ni awareness fenomenológico.

# V45 — Reference-Free Memory Under a Common Novel Probe

V45 tests whether retained internal history changes the processing of a new external input.

Each of four history templates is established first. Every history then receives the same deterministic novel probe. The probe is identical across all classes, so current external input does not identify the class.

A leave-one-parameter-out classifier is trained from clean runs and sees only the future state trajectory. It never receives memory or pressure.

For held-out parameter points, memory from a donor history class is substituted while receiver state and pressure are held fixed. The primary statistic is the paired change in donor-minus-receiver class probability relative to the intact receiver.

Pressure replacement and state replacement are controls.

This tests context-dependent processing of a common subsequent stimulus. It remains a computational dynamics test and does not establish consciousness, subjective experience, sentience, or phenomenological awareness.
