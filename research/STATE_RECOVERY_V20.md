# V20 — Recuperación del estado tras restauración demorada

## Pregunta

V15 mostró que lesionar el estado recurrente puede eliminar la identidad histórica. V20 pregunta si esa identidad puede restaurarse cuando el estado donante se reintroduce después de un delay controlado.

## Diseño

Seis puntos ciegos V12, cuatro pares de historias, diez seeds de ruido emparejados e input futuro exactamente cero.

En la frontera, el receptor comienza con state, memory y pressure comunes. En delays 0, 5, 10, 20, 40 y 80 pasos de continuación, se restaura el state recurrente del donante mientras memory y pressure actuales permanecen como los generados por la trayectoria del receptor.

El readout es affinity respecto del donante intacto frente a la referencia del donante opuesto.

## Interpretación

Si la identidad histórica se recupera después de restaurar el state donante, y la magnitud de recuperación depende del delay, esto proporciona una prueba de restauración causal complementaria a la lesión de V15.

Es un resultado dinámico computacional y no establece experiencia subjetiva ni consciencia.

# V20 — State Recovery After Delayed Restoration

## Question

V15 showed that lesioning recurrent state can remove historical identity. V20 asks whether identity can be restored when the donor state is reintroduced after a controlled delay.

## Design

Six V12 blind parameter points, four history pairs, ten matched-noise seeds, exact-zero future input.

At the boundary the receiver starts with common state, memory, and pressure. At delays 0, 5, 10, 20, 40, and 80 continuation steps, the donor recurrent state is restored while the current memory and pressure remain those generated by the receiver trajectory.

The readout is affinity to the intact donor versus the opposite donor reference.

## Interpretation

If historical identity recovers after donor-state restoration, with the amount of recovery depending on delay, this provides a causal restoration test complementary to V15 lesioning.

This is a computational dynamical result and does not establish subjective experience or consciousness.
