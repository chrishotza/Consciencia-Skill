# V29 — Aislamiento de contexto auxiliar

V29 aísla memory y pressure como variables nuisance/contextuales.

El state del receptor se fija al midpoint común A/B en todas las condiciones. Solo cambia un componente auxiliar a la vez:

- BASE: memory común + pressure común.
- MEM_A / MEM_B: memory del donante A o B, manteniendo comunes state y pressure.
- PRESS_A / PRESS_B: pressure del donante A o B, manteniendo comunes state y memory.

La geometría del state donante se fija en radio 1.1 y ángulos 0°, 90° y 180°. El input futuro es exactamente cero.

La condición 0° es un control de referencia local. Las medidas mecanísticas primarias son affinity firmada a 90° y 180°, donde una affinity firmada negativa indica inversión antipodal respecto de la identidad donante.

El experimento está diseñado para separar geometría del state de dependencia del contexto auxiliar. No establece consciencia ni experiencia subjetiva.

# V29 — Auxiliary Context Isolation

V29 isolates memory and pressure as nuisance/context variables.

The receiver state is fixed to the common A/B midpoint in every condition. Only one auxiliary component is changed at a time:
- BASE: common memory + common pressure.
- MEM_A / MEM_B: donor-A or donor-B memory, with state and pressure held common.
- PRESS_A / PRESS_B: donor-A or donor-B pressure, with state and memory held common.

The donor state geometry is fixed at radius 1.1 and angles 0°, 90°, 180°. Future input is exactly zero.

The 0° condition is a local-reference control. The primary mechanistic measurements are signed affinity at 90° and 180°, where negative signed affinity indicates antipodal reversal relative to the donor identity.

The experiment is designed to separate state geometry from auxiliary context dependence. It does not establish consciousness or subjective experience.
