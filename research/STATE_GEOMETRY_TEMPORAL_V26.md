# V26 — Persistencia temporal de la geometría del estado

V26 prueba si el código direccional del estado observado en V24/V25 sigue expresándose causalmente a través de ventanas sucesivas de continuación sin input.

Condiciones:

- seis puntos ciegos V12;
- cuatro pares de historias;
- seeds 10–19;
- memory y pressure del receptor en midpoint A/B común;
- input futuro exactamente cero;
- radios de desviación 0.0, 0.5 y 1.1;
- ángulos 0°, 90° y 180°;
- ocho ventanas consecutivas de continuación de 15 pasos.

El output primario es accuracy de identidad por ventana temporal.

Radius 0 es condición nula. Radius 0.5 representa el régimen direccional submáximo establecido. Radius 1.1 representa el régimen del radio pico de V25 sin cambiar puntos paramétricos ni regla de análisis.

El experimento es descriptivo y mecanístico. No establece consciencia ni experiencia subjetiva.

# V26 — Temporal Persistence of State Geometry

V26 tests whether the directional state code observed in V24/V25 remains causally expressed across successive zero-input continuation windows.

Conditions:
- six fixed V12 blind parameter points,
- four history pairs,
- seeds 10–19,
- common A/B receiver memory and pressure,
- future input exactly zero,
- state-deviation radius 0.0, 0.5, and 1.1,
- angles 0°, 90°, and 180°,
- eight consecutive 15-step continuation windows.

Primary output is identity accuracy per temporal window.

Radius 0 is a null condition. Radius 0.5 samples the established sub-maximal directional regime. Radius 1.1 samples the V25 peak-radius regime without changing parameter points or the analysis rule.

The experiment is descriptive and mechanistic. It does not establish consciousness or subjective experience.
