# V34 — Null angular a nivel de bloque

V34 es una réplica independiente de V33 usando history-seeds 90–99.

La estadística primaria es la diferencia media de affinity firmada entre 30° y 150°, pero la inferencia se realiza a nivel de bloque history-seed.

Cada bloque promedia seis puntos paramétricos fijos, cuatro contextos sintéticos memory/pressure y las direcciones de donante. Por ello, las miles de celdas de simulación no se tratan como miles de observaciones independientes.

El null es una permutación sign-flip estratificada dentro de cada uno de los cuatro estratos de history-pair. Un bootstrap estratificado proporciona un intervalo del 95%.

El ensemble de referencias de continuación y las continuaciones de prueba usan seeds aleatorias disjuntas.

El experimento prueba si el efecto angular es robusto después de contabilizar la estructura de medidas repetidas. No establece consciencia ni experiencia subjetiva.

# V34 — Cluster-Level Angular Null

V34 is an independent replication of V33 using history seeds 90–99.

The primary statistic is the mean signed-affinity difference between 30° and 150°, but inference is performed at the history-seed block level.

Each block averages across six fixed parameter points, four synthetic memory/pressure contexts, and donor directions. Thus the thousands of simulation cells are not treated as thousands of independent observations.

The null is a stratified sign-flip permutation within each of the four history-pair strata. A stratified bootstrap provides a 95% interval.

The continuation-reference ensemble and test continuations use disjoint random seeds.

This experiment tests whether the angular effect is robust after accounting for repeated-measures structure. It does not establish consciousness or subjective experience.
