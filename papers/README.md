# Papers

Skill-Conscious will publish a sequence of versioned working papers.

## Publication rule

A paper is only considered ready when:

1. claims are separated into source claims, project hypotheses, and empirical results;
2. the source library contains the relevant citations;
3. the implementation referenced by the paper is versioned;
4. experiments are reproducible;
5. limitations and failure cases are documented.
