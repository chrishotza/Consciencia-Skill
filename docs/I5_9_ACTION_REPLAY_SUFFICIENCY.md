# I5.9 — Action-Replay Sufficiency for Recurrent Self-Access

<a id="espanol"></a>

<details>
<summary>🇪🇸 Español — abrir</summary>

## Objetivo

I5.8 mostró que el action-clamp elimina la divergencia de estado producida por el pulso de query. I5.9 pregunta si esa divergencia puede reconstruirse **solo a partir de la secuencia de acciones que produjo el pulso**.

La comparación central es:

query perturbado → acciones del pulso → estado

frente a:

query FULL + acciones del pulso reproducidas → estado

## Condiciones

- FULL — query y acción normales.
- PULSE_SHUFFLED_QUERY — query barajada solo en el ciclo 0; después FULL.
- ACTION_REPLAY_FULL_QUERY — query FULL durante todo el horizonte, pero se fuerza la acción aplicada en cada ciclo a ser exactamente la secuencia de acciones producida por PULSE_SHUFFLED_QUERY.
- PERSISTENT_SHUFFLED_QUERY — query barajada durante todos los ciclos.

Todas las condiciones parten del mismo checkpoint.

## Hipótesis operacional

Si el efecto de la perturbación de query sobre el estado se transmite completamente por la secuencia de acciones, entonces PULSE_SHUFFLED_QUERY y ACTION_REPLAY_FULL_QUERY deberían producir trayectorias dinámicas prácticamente idénticas.

En ese caso, la diferencia query → estado queda explicada por la cadena:

query → selección de acción → acción aplicada → dinámica.

Si queda divergencia entre PULSE y ACTION_REPLAY pese a aplicar exactamente las mismas acciones, existe al menos una ruta adicional entre el estado de query y la dinámica que no está mediada por la acción aplicada.

## Endpoint primario

Diferencia absoluta entre el estado dinámico de PULSE y ACTION_REPLAY en t+1 y AUC de esa diferencia durante los ciclos posteriores.

## Endpoints secundarios

- divergencia máxima PULSE vs ACTION_REPLAY;
- divergencia PULSE vs FULL;
- divergencia ACTION_REPLAY vs FULL;
- coincidencia exacta de la secuencia de acciones aplicadas;
- diferencia entre acción seleccionada y acción aplicada durante replay;
- divergencia de query;
- divergencia de target.

## Diseño estadístico

- 24 réplicas emparejadas;
- 24 ciclos de warmup;
- 8 ciclos experimentales;
- mismo seed y checkpoint por réplica;
- 20.000 permutaciones sign-flip para el endpoint continuo.

El endpoint principal se interpreta como prueba de suficiencia de la acción para reconstruir la trayectoria, no como prueba de consciencia.

## Límites

I5.9 estudia suficiencia causal computacional dentro del runtime probado. Una reconstrucción perfecta de la trayectoria mediante action replay no demuestra consciencia ni experiencia subjetiva.

## Objective

I5.8 showed that action-clamping removes the state divergence produced by the query pulse. I5.9 asks whether that divergence can be reconstructed **from the pulse's action sequence alone**.

The central comparison is:

perturbed query → pulse actions → state

versus:

FULL query + replayed pulse actions → state

## Conditions

- FULL — normal query and action.
- PULSE_SHUFFLED_QUERY — query shuffled only in cycle 0; FULL afterward.
- ACTION_REPLAY_FULL_QUERY — FULL query throughout, but the applied action is forced each cycle to exactly match the action sequence generated by PULSE_SHUFFLED_QUERY.
- PERSISTENT_SHUFFLED_QUERY — query shuffled throughout all cycles.

All conditions start from the same checkpoint.

## Operational hypothesis

If query perturbation affects state entirely through the applied action sequence, then PULSE_SHUFFLED_QUERY and ACTION_REPLAY_FULL_QUERY should produce essentially identical dynamic trajectories.

If so, the query → state difference is explained by:

query → action selection → applied action → dynamics.

If divergence remains between PULSE and ACTION_REPLAY despite identical applied actions, at least one additional pathway exists between query state and dynamics that is not mediated by the applied action.

## Primary endpoint

Absolute dynamic-state difference between PULSE and ACTION_REPLAY at t+1 and the AUC of that difference across later cycles.

## Secondary endpoints

- maximum PULSE vs ACTION_REPLAY divergence;
- PULSE vs FULL divergence;
- ACTION_REPLAY vs FULL divergence;
- exact agreement of applied-action sequences;
- selected vs applied action difference during replay;
- query divergence;
- target divergence.

## Statistical design

- 24 paired replicates;
- 24 warmup cycles;
- 8 experimental cycles;
- same seed and checkpoint per replicate;
- 20,000 sign-flip permutations for the continuous endpoint.

The primary endpoint tests computational action sufficiency, not consciousness.

## Boundary

I5.9 tests computational causal sufficiency inside the evaluated runtime. Perfect trajectory reconstruction by action replay would not demonstrate consciousness or subjective experience.
