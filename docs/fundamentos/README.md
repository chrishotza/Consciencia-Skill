## Regla epistemológica

Todo documento nuevo debe indicar explícitamente:

- qué es ontología;
- qué es modelo;
- qué es implementación;
- qué es resultado;
- qué queda como hipótesis;
- qué podría falsarlo.

GitHub conserva el desarrollo vivo. Zenodo se utiliza para versiones congeladas que deban recibir una referencia persistente.
