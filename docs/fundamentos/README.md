## Infraestructura derivada

Los documentos anteriores alimentan el diseño de:

Consciousness Server → organismo persistente → NodeZero (futuro) → AEVUM attribution (futuro)

La infraestructura no constituye por sí misma una demostración de experiencia fenomenal.

## Regla epistemológica

Todo documento nuevo debe indicar explícitamente:

- qué es ontología;
- qué es modelo;
- qué es implementación;
- qué es resultado;
- qué queda como hipótesis;
- qué podría falsarlo.

GitHub conserva el desarrollo vivo. Zenodo se utiliza para versiones congeladas que deban recibir una referencia persistente.
