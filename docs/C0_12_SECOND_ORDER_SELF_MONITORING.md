# C0.12 — Second-Order Self-Monitoring

## Question

C0.12 asks whether the organism can build a usable model of **the error of its own first-order self-model**, and whether that second-order model becomes causally relevant to action selection.

This is a stronger self-reference question than first-order state prediction:

`state -> self-observer -> prediction error -> meta-self-observer -> action`

## Conditions

- **META_TRUE** — true first-order observer plus true second-order error observer.
- **META_PERMUTED** — same first-order observer, but second-order targets are permuted while preserving the target multiset.
- **META_BLIND** — same first-order observer, with a constant second-order error baseline.

## Primary outputs

1. second-order action difference, TRUE − PERMUTED;
2. self-prediction gain difference, TRUE − PERMUTED;
3. action difference, TRUE − BLIND;
4. gain difference, TRUE − BLIND;
5. held-out prediction-error MAE advantage of the second-order model over the constant baseline.

## Controls

No semantic input during the probe. No external retraining during the probe. The first-order observer is shared across conditions. The meta model is trained only from prediction errors generated by the first-order self-model.

## Interpretation

A specific behavioral effect from the true second-order model, together with held-out prediction of first-order model error, would support a computational form of second-order self-monitoring. It does not establish phenomenal consciousness.
