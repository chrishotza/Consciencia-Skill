# C0.18 — Lesion/Rescue of the Autonomously Acquired Second-Order Model

## Question

C0.17 showed that the PersistentOrganism can acquire the action-conditioned second-order model online, but its frozen TRUE-vs-PERMUTED control did not separate behaviorally.

C0.18 asks a different causal question:

**Does the autonomously acquired second-order model actually matter for selection at the state where it was learned?**

## Conditions

Three databases are cloned from the same post-acquisition checkpoint:

- **FULL** — learned second-order model present.
- **LESION** — second-order model replaced by an empty model.
- **RESCUE** — learned second-order model restored into the same checkpoint state.

The first-order observer, dynamic state, candidate action set, and all non-second-order state are held fixed at probe start.

## Primary outputs

- FULL − LESION action;
- FULL − LESION prediction-gain;
- RESCUE − LESION action;
- RESCUE − LESION prediction-gain.

## Interpretation

A reproducible FULL-vs-LESION effect plus RESCUE-vs-LESION recovery would provide a same-state causal necessity/rescue result for the autonomously acquired second-order mechanism.

It remains computational evidence about organization and does not establish phenomenal consciousness.
