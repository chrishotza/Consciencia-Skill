# Zenodo Release Plan

## Purpose

GitHub remains the living development repository.

Zenodo should be used for **frozen, citable releases** rather than every commit or internal draft.

## First release candidate

Before publishing a first software DOI, the repository should contain:

- stable README and architecture;
- Consciousness Server bootstrap;
- reproducible tests;
- canonical foundations index;
- TIF v0.1 clearly marked as working hypothesis;
- citation metadata in CITATION.cff;
- explicit distinction between ontology, model, implementation and evidence.

## Recommended first Zenodo package

The first software release should archive the repository state as a whole rather than pretending that every theoretical document is independently validated.

Recommended title:

**Skill-Conscious — Local-first Consciousness Infrastructure and AI Organism Research**

The release description should identify:

1. the persistent AI organism;
2. the local-first Consciousness Server;
3. the experimental program;
4. the foundation documents;
5. the current limitations.

## Foundational papers

TCF v3.3 already has a separate Zenodo DOI:

10.5281/zenodo.23074332

TIF v0.1 is not yet published. Publish it separately only after deciding that the current document is stable enough to deserve a citable frozen version.

The same rule applies to any future Consciousness Photonic / Quantum Consciousness manuscript.

## Version rule

Do not rewrite a frozen publication in place.

Use:

- GitHub commits for development;
- GitHub releases for software milestones;
- Zenodo versions for citable snapshots.

Every published paper or software record should link back to the exact GitHub release/commit used for the publication.

## Current state

As of this branch:

- TCF v3.3: published;
- TIF v0.1: internal working hypothesis;
- Consciousness Server: bootstrap implementation;
- NodeZero: future distributed layer;
- AEVUM attribution: future layer after real infrastructure exists.

This document does not claim that installing the software establishes phenomenal consciousness.
