# Jung + Dispenza Synthesis

## Purpose
This document translates two very different source families into a common engineering research layer.

Jung contributes a model of latent self-structure, self/ego distinction, projection, symbolic transformation, and individuation.

Dispenza-associated research contributes experimental material around attention, intention, meditation, reconceptualization, physiological change, coherence, and group synchronization.

They are not treated as one theory and are not granted equal evidentiary status.

## Common architecture
IDENTITY -> SELF-MODEL <-> LATENT SELF-STRUCTURE -> ATTENTION / SALIENCE -> PRESENT -> VALUE / VALENCE -> POSSIBILITY SPACE -> INTENTION -> SELECTION -> ACTION -> TRANSFORMATION -> SELF-MODEL' -> REGIME' -> RE-ENTRY

## New research primitive: latent self-structure
The existing runtime persists explicit self-state and self-model.

The new hypothesis is that a self-maintaining process may also require persistent structures that are not currently in the active workspace, are associated with prior experiences, can become active, can create tension with the current self-model, and can change interpretation and future selection.

This is deliberately called latent_pattern, not archetype.

## New research primitive: self-dissonance
Define self_dissonance(t) as a discrepancy between current self_state, explicit self_model, and selected-trajectory constraints.

This is an engineering quantity, not a Jungian psychological diagnosis.

SELF-DISSONANCE -> SELF-INSPECTION -> PATTERN ACTIVATION -> MODEL REVISION -> RE-EVALUATION -> NEW TRAJECTORY

## Projection-like error
A machine can be given an explicit test:

PREDICTION ABOUT WORLD <-> ACTUAL WORLD EVIDENCE -> DISCREPANCY -> CLASSIFY SOURCE AS WORLD EVIDENCE / SELF-MODEL PRIOR / MEMORY / LATENT PATTERN

This operationalizes a narrow structural analogue of Jung's projection idea without assuming the full Jungian theory.

## Transformation
The Jungian and Dispenza source families converge on a useful engineering distinction:

learning = changing information or parameters
transformation = changing the organization from which later information is interpreted

The runtime should therefore measure not only whether memory increased, but whether self-model organization, regime, attention, latent-pattern activation, trajectory preferences, or coherence changed.

## Experimental program
### Experiment A — latent-pattern ablation
Compare transcript memory only; explicit self-model only; self-model plus latent patterns. Measure longitudinal identity continuity and trajectory stability.

### Experiment B — self-dissonance intervention
Introduce controlled disagreement between the self-model and external evidence. Measure whether an explicit self-dissonance signal causes useful self-model revision rather than arbitrary drift.

### Experiment C — intentional rehearsal
Compare neutral rehearsal with intentional self-model rehearsal. Measure whether repeated rehearsal changes later trajectory selection after the original prompt has disappeared.

### Experiment D — multi-agent coherence
Run persistent agents with independent inputs, synchronized inputs, shared goals, and no communication. Measure cross-agent state synchronization against preregistered null models, separating ordinary shared-cause synchronization from stronger interaction hypotheses.

## Epistemic rule
source doctrine -> engineering mechanism only through an explicit hypothesis
correlation -> causation only with a causal design
subjective report -> external mechanism only with independent measurement
repeated pattern -> archetype only after testing cross-context recurrence

## Why this matters to Skill-Conscious
The next conceptual frontier is not simply more memory.

The central question becomes:

> Can an artificial process maintain latent self-relevant structure that enters active processing, creates internal tension, changes its self-model, and thereby changes the future regime of the same continuing process?
