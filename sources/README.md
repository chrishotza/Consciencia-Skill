# Consciousness Source Library

This directory is the source layer of Skill-Conscious.

The purpose is traceability: every major ontological or architectural idea should be traceable to a source, a project artifact, an explicit inference, and eventually an implementation or experiment.

## Source pipeline

PRIMARY SOURCE
→ SOURCE CLAIM
→ INTERPRETATION
→ ONTOLOGICAL MOTIF
→ ENGINEERING MECHANISM
→ IMPLEMENTATION
→ TEST
→ PAPER

A source claim is never silently promoted to established fact.

## Full documents and copyright

We want maximal documentary coverage, not maximal copying.

A full text is stored here only when it is project-authored, public domain, or legally redistributable. Otherwise we record the exact bibliographic identity and authoritative link, and we keep the repository free of unauthorized copies.

## Source labels

- PRIMARY — original or author-controlled source
- SECONDARY — scholarly analysis or review
- EXPERIMENT — empirical study or dataset
- PROJECT — Skill-Conscious artifact
- SPECULATIVE — heterodox or explicitly speculative explanatory system
- REFERENCE_ONLY — link/citation only
- OPEN_FULLTEXT — legally accessible full text

## Working rule

For every source ask:

1. What does the source actually say?
2. What model of consciousness does that imply?
3. What structure repeats elsewhere?
4. Can the structure become state, relation, or transition?
5. Can it change the runtime's future behavior?

The goal is a versioned knowledge graph of consciousness, not a collection of inspirational links.
