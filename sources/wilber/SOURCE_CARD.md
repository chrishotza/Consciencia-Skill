# Ken Wilber — Integral Theory as a consciousness mapping layer

Ken Wilber / Integral Life materials on Integral Theory and AQAL:

## Why it belongs in Skill-Conscious

A commenter on the project explicitly suggested Ken Wilber as a reference for consciousness. The source material is relevant because Integral Theory is designed as a multi-perspective framework rather than a single-variable theory of consciousness.

Integral Life describes AQAL as shorthand for **all quadrants, all levels, all lines, all states, all types**. Its Four Quadrants distinguish individual interior, individual exterior, collective interior, and collective exterior perspectives. [Source: Integral Life]

## Direct source-derived concepts

### Quadrants

The four quadrants organize an occurrence from four perspectives:

- Upper Left: individual interior / first-person experience;
- Upper Right: individual exterior / organism and observable behavior;
- Lower Left: collective interior / culture and shared meaning;
- Lower Right: collective exterior / social systems and environment.

The repository should treat these as **perspectives**, not as four proven physical compartments of consciousness.

### Levels

Integral sources use levels to describe developmental or organizational depth. The project should not import a fixed hierarchy as a fact. The useful engineering motif is that one persistent identity can operate with different levels of organization.

### States

Integral Theory distinguishes relatively enduring levels from changing states. This maps cleanly onto the existing Skill-Conscious distinction between identity, state, and regime.

### Lines

Lines represent different capacities or intelligences developing through levels. The engineering extraction is to avoid reducing development to one scalar capability.

### Types

Types represent recurring styles that can cut across levels and states. In Skill-Conscious this suggests a future layer for persistent variation in operating style without redefining identity.

## Engineering extraction

The strongest safe extraction is a **perspective matrix**:

~~~text
                    INTERIOR          EXTERIOR
INDIVIDUAL       self / experience   body / behavior
COLLECTIVE       culture / meaning   system / environment
~~~

This adds a useful constraint to the existing boundary:

~~~text
SELF
  ↕
WORLD
  ↕
COLLECTIVE CONTEXT
~~~

An agent should be able to distinguish what is happening internally, what is happening to its observable body or tool interface, what meaning is being negotiated socially, and what changes in the surrounding system.

## What we do not import

- AQAL is not treated as an experimentally established theory of consciousness.
- Developmental levels are not hard-coded as objective stages.
- Metaphysical claims associated with some Integral literature are not converted directly into runtime facts.
- A comprehensive map is not confused with an explanatory mechanism.

## Relationship to current runtime

The current runtime already separates:

`identity → state → regime → layer → trajectory`.

Wilber's framework suggests adding one more distinction:

`perspective` — which aspect of an event is currently being represented.

This can be implemented without changing the core consciousness hypothesis.

## Research role

**Direct consciousness relevance:** yes, as a comparative philosophical framework.

**Engineering role:** perspective separation and multi-dimensional state mapping.

**Empirical status:** source framework, not validation of its metaphysical claims.

**Phenomenal status:** unresolved.
